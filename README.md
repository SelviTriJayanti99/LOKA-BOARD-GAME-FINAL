## Tim Pengembang (Job Description)

Proyek Loka Boardgame Cafe dikembangkan oleh kelompok dengan pembagian tugas dan tanggung jawab sebagai berikut:

| Nama | Job Description |
|---|---|
| Selvi | Bertanggung jawab atas seluruh proses coding dan pengembangan website, meliputi frontend, backend, database, CMS, serta integrasi fitur website. |
| Zika | Melakukan pemeriksaan dan pengujian website (testing), mengecek fungsionalitas setiap fitur, serta mengidentifikasi dan membantu memperbaiki kesalahan (debugging). |
| Miska | Bertanggung jawab menghubungkan dan mengintegrasikan aset gambar ke dalam website, termasuk pengaturan path gambar agar dapat ditampilkan dengan benar. |
| Kia | Bertanggung jawab mencari, memilih, dan mengumpulkan aset gambar yang dibutuhkan untuk website, seperti foto menu, boardgame, dan elemen visual lainnya. |
